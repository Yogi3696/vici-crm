# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using GitHub's
[private vulnerability reporting](https://github.com/yogi3696/vici-crm/security/advisories/new)
feature.

Please include:

- The type of issue and where in the code it occurs
- Steps to reproduce
- The impact, and any conditions required to exploit it

You should get an initial response within a few days. Please give a reasonable window
for a fix before disclosing publicly.

## Scope

This policy covers the code in this repository.

Vulnerabilities in the Laravel framework itself should be reported to the
[Laravel security team](https://laravel.com/docs/8.x/contributions#reporting-security-vulnerabilities).
Vulnerabilities in VICIdial should be reported to the
[VICIdial project](https://www.vicidial.org/).

## Deployment note

This is early-stage software with no security review. Do not run it against production
customer data or a live dialer until it has matured and been audited.
